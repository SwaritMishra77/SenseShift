01 / The question

A new person is the real test.

A random split of ten-second clips can put one person's movements in both training and testing. Here, every recording from each test person is held out together. Phone and watch clocks differ, so their windows are evaluated separately.

The follow-up excludes the first 15 seconds after each activity starts and resamples by timestamp to 20 Hz. It reuses the original participants, so this is a sensitivity study rather than a new untouched test.

04 / Read with care

The boundaries of this result.

What this establishes

The models were trained and scored on recordings from all 51 subjects, with held-out people, source-only settings and separate device tests. The transition-exclusion and matched-input analyses were added after the first results were reviewed.

What it cannot establish

This is controlled activity data. Phone versus watch also changes sensor placement. It is not a claim about arbitrary devices, free-living behavior or healthcare use.

Where errors can hide

Mixed native recording rates, missing or broken segments, similar activities and different movement styles. Confidence calibrated on a phone can fail on a watch.

05 / Reproduce

Every number has a path back to data.

Download the official WISDM dataset or let the acquisition command fetch it. Raw data stays outside Git; the dataset is credited under CC BY 4.0.

python -m venv .venv
# activate .venv for your operating system
pip install -e '.[deep]'
senseshift acquire --download
senseshift prepare
senseshift run
senseshift report

Inspect the measured results, fixed protocol and repository README. The repository contains all source code.
