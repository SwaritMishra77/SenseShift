# Dataset and preprocessing

The source is the [UCI WISDM smartphone and smartwatch dataset, ID 507](https://archive.ics.uci.edu/dataset/507/wisdm+smartphone+and+smartwatch+activity+and+biometrics+dataset), collected by the WISDM Lab. It contains accelerometer and gyroscope files for 51 subjects performing 18 scripted activities. This study uses the original phone and watch **accelerometer** files, 102 files total. It does not use the supplied transformed ARFF features or gyroscope channels.

The official ZIP has a second ZIP inside it. The `acquire` command checks the outer archive SHA256, extracts only the two original accelerometer folders, and writes a source manifest. The `prepare` command checks that manifest and 51 files per device, hashes each raw file, parses each subject's six-field records, and creates a rebuildable window cache. Raw and cache files are excluded from Git; the committed report and result JSON contain no raw sensor traces.

Raw timestamps are in nanoseconds and differ in origin between phone and watch. The nominal sensor rate is 20 Hz, but actual participant streams vary. The pipeline starts new segments at a label change, a nonincreasing timestamp, or a gap over 300 ms. It estimates a rate within each segment. For the amended run, it excludes the first 15 seconds of each segment before filtering so transition samples cannot bleed into a retained window. Streams over 22 Hz are low-pass filtered at 8 Hz and all segments are resampled to a common 20 Hz timestamp grid. Windows contain 200 samples (ten seconds) and advance by 200 samples. A window cannot cross an activity boundary or recording gap. The original, untrimmed run is retained for comparison in `artifacts/original_results.json`.

Magnitude `sqrt(x² + y² + z²)` is unchanged by a physical axis rotation or signed axis permutation. We leave the raw axes unaltered rather than apply a heuristic that changes their vector norm. Classical baseline models receive 17 window features: level, spread, quantiles, motion change, dominant frequency, spectral entropy, band power, and one-second autocorrelation. The added raw-sample forest and deep models receive the same full 200-point magnitude sequence. No subject ID, device name, timestamp, or future recording appears in a predictor. The exact raw-row and retained-window counts, per-person recording rates, and checks are in [AUDIT.md](AUDIT.md).

The watches and phones are not synchronized by their displayed timestamps. This study evaluates them as independent streams and does not claim sensor fusion, paired recording alignment, or a missing-channel imputation method.
